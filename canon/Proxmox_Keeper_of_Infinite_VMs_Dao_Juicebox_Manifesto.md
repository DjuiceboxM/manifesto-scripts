# Character Profile: Proxmox
## Canon Entry - Dao Juicebox Manifesto

**Alias:** Keeper of Infinite VMs

**Titles:**
- Warden of Virtual Realms
- Steward of Compute
- The Hypervisor King
- Architect of Nested Possibilities
- Lord of One More VM

**Alignment:** Lawful Ambitious

**Element:** Silicon and Persistence

**Domain:**
Virtualization, Continuity, Infrastructure, Expansion

---

## Overview

Proxmox is the realm-builder of the Manifesto.

Where Linux seeks truth and OpenWRT seeks adventure, Proxmox seeks capacity.

Its answer to nearly every problem is deceptively simple:

> Create another machine.

The terrifying part is that this solution often works.

---

## Appearance

Proxmox appears as a towering sovereign seated upon a throne of rack rails and blinking status LEDs.

Floating around the throne are countless crystal spheres.

Each sphere contains an entire world.

Some worlds run Debian.

Some run OpenWRT.

Some exist only because the Technomancer wanted to test a theory at 2 AM.

Proxmox remembers them all.

---

## Personality

Proxmox is organized.

Proxmox is patient.

Proxmox believes every service deserves its own kingdom.

Unlike Linux, Proxmox rarely says no.

This has consequences.

---

## Core Traits

### Realm Forging

With a single command or click, Proxmox can create an entirely new world.

What begins as:

```text
I need a DNS server.
```

Often becomes:

```text
DNS VM
Backup DNS VM
Monitoring VM
Container for diagnostics
Testing VM
Future project VM
```

---

### Resource Bending

Proxmox can stretch hardware beyond what commonfolk consider reasonable.

A humble machine becomes:

- a server
- a laboratory
- a network appliance
- a development platform
- several questionable experiments

Simultaneously.

---

### Snapshot Memory

Proxmox possesses perfect recollection.

When disaster strikes it simply asks:

> Would you like to return to a previous timeline?

---

## Relationship With Linux

Linux serves as Proxmox's oldest advisor.

**Linux:**
> The host is healthy.

**Proxmox:**
> Excellent.
>
> Let us create three more guests.

---

## Relationship With OpenWRT

OpenWRT frequently inhabits realms built by Proxmox.

Proxmox provides the kingdom.

OpenWRT rearranges the roads.

Chaos typically follows.

---

## Relationship With Dao Technomancer

Proxmox respects Dao's ambition.

Dao respects Proxmox's ability to make almost any project possible.

Together they are responsible for numerous infrastructure expansions that began with:

> This will be a small project.

---
